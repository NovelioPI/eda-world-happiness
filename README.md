# 🌍 EDA: World Happiness Report

This project performs Exploratory Data Analysis (EDA) on the World Happiness Report dataset. The dataset includes socio-economic indicators from countries around the world and how they relate to happiness levels.

## 📊 Dataset
- Source: [Kaggle: World Happiness Report](https://www.kaggle.com/datasets/unsdsn/world-happiness)
- Features include:
  - Happiness Score
  - GDP per Capita
  - Social Support
  - Healthy Life Expectancy
  - Freedom, Trust, Generosity

## 🧪 Goals
- Understand the global distribution of happiness
- Identify which factors are most correlated with happiness
- Visualize patterns and trends

## 🛠 Tools
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## 📈 Highlights
- Social support, GDP, and Healthy have strong positive correlations with happiness
- Countries with high corruption perception tend to score lower in happiness
- Visual insights from scatter heatmaps, plots, and boxplots
